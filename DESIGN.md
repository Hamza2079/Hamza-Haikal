# HAMZA PORTFOLIO DESIGN SYSTEM

## Identity

This portfolio should feel like a premium frontend engineer portfolio.
Not an AI-generated template.

The experience should feel:
- cinematic
- smooth
- minimal
- modern
- intentional
- interactive

Inspired by:
- Linear
- Vercel
- Apple
- Rauno
- Awwwards portfolios

Avoid:
- generic AI gradients
- overused glassmorphism
- random floating blobs
- too many colors
- excessive glow
- repetitive fade-up animations

The website should feel handcrafted.


# Core Visual Style

## Theme

Dark mode first.

Use deep blacks instead of gray backgrounds.

Background:
#09090B

Surface:
#111113

Soft Border:
rgba(255,255,255,0.08)

Primary Text:
#FFFFFF

Secondary Text:
rgba(255,255,255,0.65)

Accent:
#8B5CF6

Accent Hover:
#A78BFA


# Typography

Use:
- Satoshi
or
- General Sans

Headings should feel massive and cinematic.

Large spacing.
Minimal wording.
High contrast.

Avoid:
- tiny text everywhere
- too many paragraphs
- generic developer wording


# Layout Philosophy

The website should NOT feel section-based.

It should feel like a scrolling experience.

Use:
- sticky sections
- pinned scrolling
- cinematic transitions
- large vertical spacing
- immersive fullscreen blocks

Avoid:
- simple stacked cards
- traditional portfolio layouts
- boxed content everywhere


# Hero Section

The hero must feel powerful and minimal.

Large typography.

Example tone:
"Frontend engineer crafting smooth digital experiences."

Hero should contain:
- subtle text reveal animation
- mouse reactive glow
- soft background noise/grid
- smooth entrance animations
- premium spacing

Avoid:
- typing animation
- rotating titles
- generic introduction layouts


# Motion System

Animations should feel expensive.

Use:
- Framer Motion
- GSAP ScrollTrigger
- Lenis smooth scrolling

Animation style:
- smooth
- slow
- intentional
- subtle

Avoid:
- bouncing animations
- aggressive motion
- too many fade-ups
- flashy effects

Preferred animations:
- text reveal
- scale on scroll
- pinned sections
- horizontal scrolling sections
- staggered entrances
- opacity transitions
- cinematic image movement


# Projects Section

Projects should become the main experience.

Do NOT use simple cards.

Instead:
- fullscreen project showcases
- sticky scrolling transitions
- large previews
- immersive layouts
- alternating compositions

Each project should feel like a product launch section.

Project interactions:
- hover video preview
- smooth scaling
- animated cursor feedback
- cinematic transitions


# Navbar

Floating navbar.

Minimal.
Blurred background.
Thin border.

Behavior:
- hide on scroll down
- show on scroll up

Very clean.


# Background Effects

Use very subtle:
- grain/noise
- grid overlays
- radial gradients

Effects must remain soft and premium.

Never overpower content.


# Buttons

Buttons should feel tactile and modern.

Rounded-xl.

Hover:
- soft glow
- slight scale
- smooth easing

Transitions:
300ms cubic-bezier easing


# Skills Section

Avoid boring icon grids.

Use:
- scrolling marquees
- interactive pills
- animated stacks
- grouped technologies

Make it feel alive.


# Contact Section

Minimal and elegant.

Large typography.
Simple CTA.

Avoid:
- huge forms
- too much text


# Overall Experience

The website should feel:
- premium
- memorable
- handcrafted
- motion-driven
- developer-focused

The user should remember the scrolling experience more than the UI itself.


# Technical Requirements

Use:
- React
- TailwindCSS
- Framer Motion
- GSAP
- Lenis

Performance is important.

Animations must remain smooth on lower-end devices.

Use responsive layouts for mobile and desktop.


# Important

Do not redesign this as a generic SaaS landing page.

Do not make it look AI-generated.

Every animation and spacing decision should feel intentional.
